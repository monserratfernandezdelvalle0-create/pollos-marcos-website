# Pollos Marcos - Sitio Web Oficial

¡Bienvenido al repositorio del sitio web de Pollos Marcos!

## 📍 Descripción

Sitio web oficial de **Pollos Marcos**, especialista en pollos asados y verduras frescas en Medellín, Veracruz. Este sitio proporciona información sobre nuestros productos, ubicación y opciones de contacto.

## 🌐 Características

- ✅ Diseño responsive y moderno
- ✅ Navegación intuitiva
- ✅ Sección de productos destacados
- ✅ Información de contacto y ubicación
- ✅ Integración con WhatsApp para pedidos
- ✅ Paleta de colores profesional
